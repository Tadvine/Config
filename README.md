# دفتر حساب بدهکاری و بستانکاری

نسخه وب‌اپلیکیشن فارسی، راست‌چین، تیره و ریسپانسیو.

## امکانات
- افزودن، ویرایش و حذف اشخاص
- ثبت، ویرایش و حذف تراکنش بدهکاری یا بستانکاری
- محاسبه خودکار جمع‌ها و مانده حساب هر شخص
- جست‌وجوی اشخاص
- ورود و نمایش تاریخ شمسی مانند ۱۴۰۵/۰۷/۲۱ و فیلتر بازه تاریخ شمسی
- فونت بزرگ‌تر و خواناتر
- ذخیره محلی در مرورگر
- پشتیبان‌گیری JSON و بازیابی با تأیید جایگزینی اطلاعات
- قابلیت نصب به‌صورت وب‌اپلیکیشن (PWA)

## اجرا و نصب
فایل `index.html` را باز کنید. برای نصب PWA و حالت آفلاین، فایل‌ها را روی هاست استاتیک HTTPS قرار دهید و در Chrome گزینه Add to Home screen یا Install app را بزنید.

## ذخیره‌سازی
اطلاعات در مرورگر همان دستگاه ذخیره می‌شود. مرتب فایل پشتیبان بگیرید. بازیابی، اطلاعات فعلی را با فایل پشتیبان جایگزین می‌کند. این بسته APK مستقل نیست؛ برای ساخت APK باید رابط را در پوسته اندرویدی قرار داد.
